# Meyerland dental website concept

An independent, unsolicited redesign created by M.Unse for a prospective dental-practice client. This is not commissioned work or the clinic’s official website.

## Preview

This is a buildless static website. Serve this directory with any static web server, for example:

```sh
python -m http.server 4174 --bind 127.0.0.1
```

Then visit http://127.0.0.1:4174/. No dependencies, API keys, database or build step are required. Vercel can serve index.html from the repository root.

## Portfolio behavior

- Visible independent/demo notice and noindex metadata.
- Responsive navigation, native FAQ disclosures and a keyboard-accessible booking dialog.
- The booking form only previews service/time choices locally. No network request, personal-data fields, storage or real appointment reservation is involved.
- Web-development enquiries link separately to M.Unse’s public email. No clinic telephone, location-specific contact link or third-party booking action is connected.
- Repeated hero content, malformed wrapper markup, unsupported statistics and placeholder social/legal links were removed.
